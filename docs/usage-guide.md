# yt-dlp GUIで動画・再生リストを管理する方法（Windows 10/11）

神 DOWNLOADER v3.1 HERA Edition は、保存する権利・許諾のある動画をPCやNASで管理するための無料・広告なしのWindows向けツールです。

[最新版の配布ページ](https://github.com/TakaLabo-Official/God-Downloader/releases/latest) ｜ [主な機能・利用条件](../README.md)

## 導入前の確認

Windows 10/11、.NET Framework 4.8以上を想定（64ビット推奨）。yt-dlp、FFmpeg、Deno は別途導入が必要です。外部ツールを含めた導入方法と実行方法は配布ZIPのREADME.txtに従ってください。GitHubのSource codeはアプリ本体ではありません。

未署名なのでWindowsの警告が出る場合があります。公式配布ページのファイル名・README掲載のSHA-256を確認し、セキュリティソフトで検査してください。保護機能を無効化する必要はありません。

## 再生リストの定期確認とキュー管理

- 保存権限のある対象を選び、不要な項目を除外します。
- 日単位の定期確認と未保存項目の照合を活用します。
- キューと履歴で保存状態を確認し、必要に応じ停止・再開します。

PCが停止している間もクラウド上で実行するサービスではありません。細かな操作手順は同梱説明書を参照してください。

## NAS保存を利用する場合

ローカル作業領域を経由するNAS保存に対応。PC側とNAS側の空き容量、接続状況、保存先の書き込み権限を確認してください。最初は小さな保存対象で確認するのがおすすめです。大切なファイルはバックアップしてください。

## トラブル時の確認

外部ツールの導入状態、保存先、容量、キューや履歴を確認してください。問い合わせ時は利用環境・発生条件を添え、個人情報や認証情報を含むログはそのまま公開しないでください。

本ソフトはアクセス制御や技術的保護手段の回避を目的としたものではありません。保存対象の権利と各サービスの利用条件を守ってください。別PC・新規環境などの網羅的な検証は未実施です。
