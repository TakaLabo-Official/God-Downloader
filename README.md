# 神 DOWNLOADER — HERA Edition

**Windows向け 動画・再生リスト保存管理ツール**

開発元：Taka Labo ｜ 無料・広告なし ｜ v3.1

## 主な機能

- 動画・再生リストの保存管理、対象動画の選択と除外
- 日単位の定期確認、未保存項目の照合、キューと履歴、停止・再開
- PC保存、ローカル作業領域を経由したNAS保存、容量監視
- HERAの状態表示、ダークUI、タスクトレイ

## ダウンロード

[GitHub Releases](https://github.com/TakaLabo-Official/God-Downloader/releases/latest) の `God_Downloader_v3.1_HERA_Edition.zip` を取得し、展開してください。

Windows 10/11（64ビット推奨）、.NET Framework 4.8以上を想定しています。開発者の実機で検証済みですが、別PC・新規環境、全DPI・長時間・異常系の網羅検証は未実施です。外部ツール（yt-dlp、FFmpeg、Deno）は同梱していません。配布ZIP内のREADME.txtに従って導入してください。

未署名のためWindowsの警告や起動制限が出る場合があります。正規配布元とハッシュを確認し、セキュリティソフトで検査してください。保護機能の無効化は不要です。
