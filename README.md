# 神 DOWNLOADER — yt-dlp GUI・動画／再生リスト管理（Windows）

**Windows向け無料の動画・再生リスト保存管理ツール — HERA Edition**

yt-dlpを使った動画保存をGUIで管理し、許諾のある動画や再生リストの定期確認、保存済み項目の管理、PC・NASへの保存をまとめて行いたい方向けです。

Free, ad-free Windows GUI for yt-dlp with playlist monitoring, download queues, history and local/NAS storage. External tools are installed separately.

開発元：Taka Labo ｜ 無料・広告なし ｜ v3.1

**[最新版のダウンロード / Download latest release](https://github.com/TakaLabo-Official/God-Downloader/releases/latest)**

## 主な機能

- 動画・再生リストの保存管理、対象動画の選択と除外
- 日単位の定期確認、未保存項目の照合、キューと履歴、停止・再開
- PC保存、ローカル作業領域を経由したNAS保存、容量監視
- HERAの状態表示、ダークUI、タスクトレイ

## 使い方・よくある質問 / Getting started & FAQ

[動画・再生リスト管理の導入ガイド（日本語）](docs/usage-guide.md)

- **yt-dlpのコマンド操作が苦手でも使える？** GUIで保存対象、キューや履歴を管理できます。外部ツールの初期導入は同梱READMEの手順に従ってください。
- **毎日同じ再生リストを確認したい。** 日単位の定期確認と未保存項目の照合に対応しています。常時稼働・クラウドサービスではありません。
- **NASに保存できる？** ローカル作業領域を経由してNASに保存できます。接続状況・空き容量・書き込み権限を確認してください。
- **無料？** 無料・広告なし。任意の開発支援は機能の利用条件ではありません。
